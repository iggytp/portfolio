## Contenido del portfolio

El portfolio está formado por cuatro páginas HTML:

- **`index.html` — Inicio:** presentación personal y profesional, perfil como graduado en Ingeniería Matemática Aplicada al Análisis de Datos y estudiante de Ingeniería Informática, habilidades técnicas, formación académica, proyectos destacados y disponibilidad.
- **`proyectos.html` — Proyectos:** recopilación de siete proyectos relacionados con análisis de datos y Machine Learning, modelado de energía solar en Aruba, predicción de mercados financieros, pipelines de datos geográficos y dashboards desarrollados en el entorno profesional de Civitatis, simulación de circuitos con NI Multisim y prototipado UI/UX con Penpot.
- **`sobre-mi.html` — Sobre mí:** trayectoria personal y académica, cita de Grace Hopper, línea de tiempo con hitos formativos y profesionales, vídeo introductorio sobre Machine Learning, preguntas frecuentes y nivel técnico en Python, SQL y Docker.
- **`contacto.html` — Contacto:** formulario HTML para plantear consultas o proyectos, con campos de contacto, tipo y modalidad del proyecto, servicios solicitados y mensaje. También incluye enlaces al correo electrónico, GitHub y LinkedIn.
